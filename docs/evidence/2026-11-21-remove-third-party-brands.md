# Removal of third-party brand names — 2026-11-21

The owner asked why real companies were named in this repository and asked for every mention to be removed. Eleven third-party brands appeared as development sources. Their published brand guidelines had been used to develop and test the Studio's guideline import: reading colour values from PDF tables and fragmented text, grouping rule statements for review, and the authored colour-relationship model. None of them was product content.

## What changed

- **Deleted.** Six evidence records existed only to describe work on those sources: the per-source development case files and their receipts, an evaluation-preparation receipt and a paired-development receipt under `docs/evidence/brand-guideline-import/`. The `web/scripts/guideline-application-proof.mjs` harness was also deleted. It was pinned to one company's guideline PDF by hash, page numbers and copied colour names, and could not run without that file. Its `proof:guideline-application` script and its two README paragraphs went with it.
- **Neutralised.** Every other mention became a stand-in, used the same way on both code lines: one letter per brand ("Brand A", "Brand B" and so on in prose; `brand-a`, `brand-b` in ids and paths; `https://brand-a.example/…` for URLs). This line uses Brand A to Brand H; Brand I to Brand K appear only on the private line, which held the other names. Links to the deleted records now read "(record removed)". Recorded hashes and counts in historical receipts are unchanged; they describe the original runs.
- **Kept.** Ordinary words were left alone: "Medium" as a severity or font weight, and the "Open website capture" control label. Mozilla's pdf.js links, the MIT licence and the presets the grid library ships (Material, Carbon, USWDS, Fluent and others) were also kept.
- **Images.** All 42 tracked images were inspected. They show only Teul's interface, the fictional Harbor fixtures and Wada colours. None needed to change. This line has no tracked zip files.

## Guard

`npm run verify:no-third-party-brands` runs `scripts/verify-no-third-party-brands.mjs` and its tests. It is a release-gate step after the candidate artifact checks, so both built bundles are scanned. The names are stored as fragments, so the guard does not trip on itself. Its rules are case-aware: the two names that are also ordinary nouns fail only when capitalised or used inside an identifier. The publisher that shares its name with a size is caught only by its domain and id forms. Run against the untouched `ad0a7bb` tree, the guard reports 172 hits in 23 files. That matches the case-insensitive search once the six "Open website capture" files are excluded. The current tree passes. Limits: the publisher's capitalised name in prose (for example a heading) cannot be told apart from the size word and is not caught. Binary files are checked for domains only. `web/dist` is not scanned. The third brand's two-word name, inside another proper name, would trip the phrase rule and must be written another way.
