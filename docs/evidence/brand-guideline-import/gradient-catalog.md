# Catalog-supported gradients in Studio

Studio can suggest a gradient from a reviewed PDF, Figma capture or website snapshot while retaining the original source system. The designer chooses one to three source references, explicitly permits a library, and compares up to three distinct proposals. A selected proposal enters the existing two-to-five-stop editor and can be saved or exported as SVG, CSS and JSON. This is partial TASK-008 / REQ-009–010 and TASK-009 evidence, not completion of the full PRD.

## Source identity and generation

Original stops retain exact reviewed values and start locked. Proposed stops have separate catalog references and are never inserted into the reviewed source model. A permission record binds the source/review hashes, use, mode, selected family/scheme, reference colors and permitted members. It cannot override source bans, unresolved or contradicted claims, conflicts, missing rule decisions or a closed source palette.

One search examines at most eight catalog families and three members per family. Wada retrieval finds historical combinations near the selected references and proposes an unmatched companion. Werner proposes nearby historical reference colors without claiming an original pairing. Radix uses an explicitly chosen published light/dark scheme. Historical values retain their approximation disclosures. Exactness for Radix applies to authored library stops; Teul generates intermediate gradient colors.

Restrained exploration uses a direct OKLab route and an added-stop distance of 0.05–0.18 from the closest selected reference, targeting 0.10. Expressive exploration uses the shorter OKLCH hue route and a range of 0.12–0.40, targeting 0.24. These are versioned exploration heuristics. Retrieval distance plus distance from the selected target orders eligible proposals; neither is a beauty score. The existing 0.02 minimum-change policy excludes additions too close to any current source color, including unselected colors. Selected proposals differ in added paint by at least 0.05. The same angle and anchor positions are used throughout a comparison, so angle-only changes cannot masquerade as new directions.

Each eligible proposal passes the current continuous compiled-paint assessment for its actual declared foreground/coverage and additional designer limits. A bounded search with no result says so without asserting universal impossibility. Original source constraints stay binding. Continuous fidelity to the ideal interpolation path remains uncertified; the current compiler's dense oracle measures observed approximation error only.

## Retention and recovery

Authored selection V3 records each stop as source or catalog. Workspace V6 retains it beside unchanged source-project bytes. A detached lookup against the pinned canonical catalog validates members and provenance without rerunning current retrieval rankings. Wrong source/review, family, scheme, member, pin, paint or origin references are rejected. Old workspace versions cannot accept these semantics under a rewritten digest.

Flat refresh lineage V5 retains the previous selection. Refresh remaps verified unchanged source references and foreground, retains the permitted catalog member subset and pins, and requires the exact compiled paint. It cannot renew source rule decisions or treat matching RGB as proof of source identity. Legacy source-only and assessed-gradient behavior remains unchanged.

The shared editor labels proposed stops, scopes permission to the chosen use/mode, and provides an explicit return to source colors. Source text choices remain source-only. Changing a checked design removes its old preview/export until it is remade. Failed checks remain recoverable as JSON/project data. Own selections preserve the comparison set; edits, cancellation and later project opens invalidate stale background work.

## Remaining and release state

This is local implementation and verification. The controls and retained artifacts are usable without a Figma plugin. Human visual acceptance, the held-out quality benchmark, full continuous ideal-path fidelity, additional source-rule interpretation and broader generation still remain. Passing the numerical checks does not establish that a gradient suits a brand. No private connector/provider, native Figma paste destination or deployed release is qualified by these synthetic fixtures. This slice is not integrated, pushed or deployed.
