# Teul release notes, November 2026

## The plugin

- **A new layout.** A side rail with four places: Color, Grids, Check and
  More.
- **Color.** Browse the Sanzo Wada and Werner libraries, open a color to see its
  combinations, and build a color system from it in one flow.
- **Building a system.** Choose what to create (Figma Variables, Color Styles,
  or a color-system frame in one of three levels of detail), see how many
  tested pairings pass, and choose what happens if the system already exists:
  update it, make a copy, or rename. You can also take the result as CSS,
  Tailwind or JSON.
- **Grids.** The grid library, with a detail view for each preset.
- **Check.** Contrast checks with clear pass and fail states.
- **More.** Light, dark or automatic appearance, the document's color profile,
  and notes on where the historical colors come from.

Screenshots of every screen in light and dark are in
[`docs/screenshots/2026-11-redesign/`](screenshots/2026-11-redesign/).

## Teul Studio (web)

The example chart for choosing colors in context now uses neutral sample data,
and the guideline tools received fixes and new tests.
